# Kuličkové Tvary PRO v2

- 60 deterministicky generovaných sestavitelných úkolů (20 v každé obtížnosti).
- Denní výzva.
- 3D/plastický vzhled kuliček.
- Volné skládání.
- Editor vlastních předloh s uložením v prohlížeči.
- Rekordy: nejlepší čas a počet tahů.
- Automatické ukládání rozehrané hry.
- Zvuk při dokončení.
- PWA instalace a offline cache.
- Responzivní PC, tablet, mobil.
- Myš, dotyk a klávesnice.

## GitHub Pages
